## Naming Conventions

- Variable: `lowerCamelCase`
- Class Name: `UpperCamelCase`
- Functions: `lowerCamelCase`
- Type (type/interface): `UpperCamelCase`
- Constant: `UPPER_SNAKE_CASE`
- Component: `UpperCamelCase`
- TypeScript File Name: `lowerCamelCase`
- TypeScript Component File Name: `kebab-case`
- Do not use a name whose meaning is not decided by itself (such as `factor`, `value`, `data` and `info`).
- Put the role in the name: `...Multiplier` for a number to multiply by, `...Ratio` for a ratio, and `...Zoom` for an absolute value.
- If a name still needs a comment to be understood, change the name.
