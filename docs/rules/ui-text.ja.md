## UI文言の表記ルール

画面に表示される日本語の文言（ボタン、ツールチップ、トースト、エラー、見出し、説明文など）と、`src/app/layout.tsx`の metadata description に適用します。
このルールは表記だけを定めます。
文体（体言止めか、です・ます調か）は定めません。
`docs/`や README など、開発者向けの文章は対象外です。

### 数値と単位

数値と単位の間にスペースを入れません。

- 例: `400%`、`30文字以内`
- 避ける: `400 %`、`30 文字以内`

### 英数字

- 英数字と記号（`%`、`/`など）は半角にします。
- カタカナは全角にします。
- 日本語と半角英数字の間にスペースを入れません。
- 例: `LLMに渡す`、`Backspaceキー`
- 避ける: `LLM に渡す`、`Backspace キー`

### 括弧

日本語の文中では、全角の括弧（）を使います。

- 例: `確認コード（6桁）`
- 避ける: `確認コード(6桁)`

### 句点

句点の有無は、1つの表示要素（トースト、`<p>`、description など）に含まれる文の数で決めます。

- 1文だけなら、句点を付けません。
  - 例: `保存に失敗しました`
- 複数文なら、すべての文に句点を付けます。
  - 例: `倍率は400%以下にしてください。400%に設定しました。`

### 改行

複数文の説明は、文ごとに`<br />`で改行します。

```tsx
<p>
  現在はゲストとして利用中です。
  <br />
  サインインすると、現在のゲストのスケッチは表示されなくなります。
</p>
```

### 用語の統一

同じ意味の言葉は、次の表の表記に統一します。

| 使う表記       | 使わない表記                                               |
| -------------- | ---------------------------------------------------------- |
| サインイン     | ログイン                                                   |
| サインアウト   | ログアウト                                                 |
| アカウント登録 | サインアップ、新規登録                                     |
| スケッチ       | ワイヤーフレーム、図、キャンバス（スケッチ本体を指す場合） |
| ゲスト         | 匿名ユーザー、ビジター                                     |
