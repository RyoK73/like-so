## 命名規則

- 変数: `lowerCamelCase`
- クラス名: `UpperCamelCase`
- 関数: `lowerCamelCase`
- 型(type/interface): `UpperCamelCase`
- 定数: `UPPER_SNAKE_CASE`
- コンポーネント名: `UpperCamelCase`
- TypeScript ファイル名: `lowerCamelCase`
- TypeScript コンポーネント ファイル名: `kebab-case`
- 単独では意味が決まらない名前(`factor`、`value`、`data`、`info` など)を使わない。
- 掛ける数は `〜Multiplier`、割合は `〜Ratio`、絶対値は `〜Zoom` のように、役割を名前に含める。
- 名前を付けたあと、コメントを足さないと意味が伝わらないなら、名前を直す。
