# 固定枠とパン・ズーム

## 概要

**枠**は`frame_size`のフレームを意味します。`<canvas>`要素ではありません。

スケッチは、固定の枠(`sketch.width` × `sketch.height`、単位はpx)の中に描きます。
キャンバス要素は、画面に収まる大きさに縮め、枠の内容をその中でパンとズームします。
パンとズームは、fabricの`viewportTransform`で行います。
計算はfabricに依存しない純粋関数(`src/sketch-detail/viewport/viewportMath.ts`)にまとめています。

## 用語と座標

| 用語       | 意味                                                                                 |
| ---------- | ------------------------------------------------------------------------------------ |
| 枠         | スケッチの描画範囲。`sketch.width` × `sketch.height`                                 |
| 領域       | ツールバーを除いた、キャンバスを置ける画面の空き部分。`ResizeObserver`で測ります。   |
| 要素       | `<canvas>`要素。領域に収まる最大の大きさで、枠と同じ縦横比です。                     |
| シーン座標 | 枠の左上を原点とした、図形が持つ座標。ズームやパンでは変わりません。                 |
| 画面座標   | 要素の左上を原点とした、画面上の位置。                                               |
| ズーム`z`  | 表示倍率。`1`が100%です。                                                            |
| `t`        | シーンの原点(枠の左上)が、画面のどこに表示されるか。`(tx, ty)`で表します(単位はpx)。 |

`viewportTransform`は、パンとズームだけなら`[z, 0, 0, z, tx, ty]`の形になります。
シーン座標`s`と画面座標`p`の関係は、次の式です。

```
p = s × z + t
s = (p − t) / z
```

ズームとパンで変わるのは、`z`と`t`だけです。
図形のデータ(シーン座標)は変わらないので、保存される内容にも影響しません。

## 初期フィット

要素は、領域に収まる最大の大きさにします。
枠が領域より小さい場合は、拡大せず、100%で枠と同じ大きさにします。

```
scale = min(1, 領域の幅 / 枠の幅, 領域の高さ / 枠の高さ)
要素の幅 = round(枠の幅 × scale)
要素の高さ = round(枠の高さ × scale)
初期ズーム = scale    (丸めない)
初期のt = (0, 0)
```

| 枠       | 領域    | 要素    | 初期ズーム |
| -------- | ------- | ------- | ---------- |
| 400×300  | 900×600 | 400×300 | 1          |
| 1200×800 | 900×600 | 900×600 | 0.75       |
| 1200×800 | 900×300 | 450×300 | 0.375      |

ウィンドウをリサイズしたときは、ズームとパンを保たず、初期表示に戻します。
ズームとパンの状態は保存しません。開くたびに初期表示から始まります。

## ズーム

ズームは10%〜400%に制限します(`clampZoom`)。

### ポインタ中心のズーム

ポインタの真下にある点が、ズームの前後で同じ画面位置に残るようにします。
つまり、ズームの前後で、ポインタ下のシーン座標`s`が変わらない、という条件です。

1. ポインタの画面座標`p`から、ポインタ下のシーン座標を求めます: `s = (p − t) / z`
2. 新しいズーム`z'`を決めます: `z' = clamp(z × 倍率, 0.1, 4)`
3. `s`が同じ`p`に表示されるように、`t'`を決めます: `t' = p − s × z'`

数値例(現在のズーム1、`t = (0, 0)`、ポインタ`(100, 50)`、掛ける倍率2):

- `s = (100, 50)`
- `z' = 2`
- `t' = (100 − 100 × 2, 50 − 50 × 2) = (−100, −50)`
- 検算: `s × z' + t' = (100, 50)`。元のポインタ位置に戻ります。

`z'`を先にクランプしてから`t'`を計算します。
`t'`を先に計算して`z'`だけ丸めると、ポインタ下の点がずれます。

## パン範囲

枠が画面から完全に出てしまうのを防ぎます。
要素と枠が、最低`m`px(50px)重なる範囲に`t`を制限します(`clampPan`)。

```
枠の画面上のサイズ = 枠の幅 × z (高さも同様)
m' = min(50, 枠の画面上のサイズ)
tx の範囲: m' − 枠の画面上の幅  ≤  tx  ≤  要素の幅 − m'
ty の範囲: m' − 枠の画面上の高さ ≤  ty  ≤  要素の高さ − m'
```

数値例(要素900×600、枠1200×800、ズーム1): `tx`の範囲は`−1150 〜 850`、`ty`の範囲は`−750 〜 550`です。

## ホイール操作

`resolveWheelAction`が、ホイールイベントを次のいずれかに振り分けます。

| 条件                   | 動作                                                                         |
| ---------------------- | ---------------------------------------------------------------------------- |
| Ctrl(ピンチ操作を含む) | ズーム。倍率は`0.999 ** deltaY`。Shiftが同時に押されていても、ズームを優先。 |
| Shift                  | 横パン。`deltaX`と`deltaY`の絶対値が大きい方を使う。                         |
| 修飾キーなし           | `deltaX`で横パン、`deltaY`で縦パン(トラックパッドでは斜めも可)。             |

- パンの量は、`delta`をそのまま画面pxとして使い、`t`から引きます(`ty −= deltaY`)。
- ズームの倍率が`0.999 ** deltaY`なのは、回した量に比例させ、往復すると元に戻すためです。
  `deltaY = −100`(マウスの1ノッチ上)は約1.105倍、`+100`は約0.905倍です。
- Shift+ホイールは、ブラウザによって`deltaY`が`deltaX`に入れ替わって届きます。
  このため、Shiftのときは、どちらか大きい方を使います。
- スペースを押しながらドラッグすると、ドラッグした量だけ`t`を動かします(パン範囲で制限)。

## 図形の中心の制限と作成位置

図形は、**中心**が枠内にあればよいことにします。
枠より大きい図形も追加でき、枠からはみ出した部分は、クリップせずに薄く表示します。

- 移動: 中心が枠の外へ出そうなとき、中心を枠の縁に止めます(`clampCenter`)。
  拡大縮小と回転は、制限の対象外です。
- 読み込み: すでに中心が枠外にある図形は、そのまま保持します。
- 作成: 画面中央のシーン座標を、枠内にクランプした位置に作成します(`getNewShapeCenter`)。

```
画面中央のシーン座標 = ((要素の幅/2 − tx) / z, (要素の高さ/2 − ty) / z)
```
